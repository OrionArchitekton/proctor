Proctor — the agent that QAs other agents

UiPath AgentHack 2026 · Track 3: UiPath Test Cloud

Technical brief · Dan Mercede · github.com/OrionArchitekton/proctor (MIT) · Built with Claude Code, the coding agent

Proctor regression-tests non-deterministic AI automations — it learns each automation's behavioral contract, catches when a model or prompt change silently breaks it, classifies the drift, and escalates real regressions to a human, all governed by UiPath.

The problem & the method

AI automations are non-deterministic: the same input rarely yields byte-identical output, so naive assertEqual(output, expected) either flakes constantly or passes on garbage. Proctor solves this with a behavioral contract + drift classification approach:

  • Learn — run the automation over sample inputs; synthesize a versioned Contract: per-field assertion altitudes (structural / exact / semantic) plus absolute domain invariants (e.g. sum_line_items_eq_total).
  • Run — re-evaluate against the contract using invariants + semantic similarity, never brittle equality.
  • Classify — a drift classifier decides real-regression (alert), legitimate-evolution (still correct → propose a contract patch), or flaky (within tolerance). This is the novel core: distinguishing "it broke" from "it changed but is still correct."
  • Escalate — real regressions pause a durable workflow on a human-approval hook that survives interruptions (verified against the runtime event log, not mocked).

Architecture — two altitudes that never compete

UiPath Automation Cloud — ENTERPRISE CONTROL PLANE Test Cloud · Orchestrator (triggers) · Action Center (approvals) · audit ▲ results / approvals │ triggers a run │ ▼ Proctor — DURABLE QA AGENT (TypeScript / Next.js on Vercel) Vercel Workflow = the agent's durable runtime (survives interruptions) Contract Learner → Assertion Engine → Drift Classifier → Heal + Approval hook │ exercises ▼ SUT: invoice-extraction agent (deliberately non-deterministic; "degraded" mode mis-extracts totals)

One UiPathGateway adapter is the seam: LocalGateway (disk + dashboard, runs anywhere) ↔ TestCloudGateway (real UiPath REST). UiPath governs at the org level; Vercel Workflow makes the agent itself durable — they operate at different altitudes, so "UiPath orchestrates" and "the agent is durable" are both true.
